# Projet Kingso

Objectif :
Créer une plateforme moderne pour Kingso, l'assistant de Le Roi Solaire.

Technologies :

* Next.js
* TypeScript
* Tailwind CSS

Règles générales :

* Toujours privilégier du code simple et lisible.
* Utiliser des composants réutilisables.
* Optimiser le SEO.
* Optimiser le responsive mobile.
* Utiliser TypeScript correctement.
* Expliquer les modifications avant les gros changements.

Architecture prévue :

Front public :

* Présentation de Kingso
* Chat assistant
* FAQ

Back-office :

* Gestion des catégories
* Gestion des documents
* Gestion des FAQ
* Historique

Base documentaire :

* Documents publics
* Documents internes
* Documents franchisés (plus tard)

Important :
Kingso doit répondre uniquement à partir de la base documentaire.
S'il ne trouve pas une information, il doit l'indiquer clairement.
